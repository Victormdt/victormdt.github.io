Om meg

Hei! Jeg heter Victor Mandt 👋

Jeg er utdannet ergoterapeut, og er autorisert helsepersonell, og har bred erfaring fra helsesektoren. Nå studerer jeg Anvendt Datateknologi på OsloMet, og kombinerer Helse og Informatikk, for jeg synes digitale løsninger burde bli utviklet fra personer som har direkte hands on erfaring fra feltet.

IT og programmering er noe jeg har alltid hatt interesse for. Helt siden jeg var liten. Om det er å konvertere en gammel macbook til en Debian Server sånn at jeg ikke trenger å betale for Google Drive, eller å leke rundt med Rasberry Pi sånn at familieruteren ikke fikk reklame på internett, så har programmering alltid vært der for meg.

Nå utvikler jeg programmer hvor jeg ser det trengs. Som f.eks LydtilVibrasjon, eller Tekst TV, så kan jeg bruke min erfaring fra helse og Informatikk til å lage programmer som kan hjelpe en som har behov for det.

LydTilVibrasjon

Status: Ferdig

En app jeg laget for personer med redusert hørsel. Appen fanger lyd fra en Windows datamaskin, og konverterer lyden til vibrasjoner. Appen fanger om lyden kommer fra venstre eller høyre side, og vibrerer på den siden, så det blir en 3D vibrasjon. Skrevet på Python, og fungerer gjennom XInput

  • Python
  • XInput

Tekst-TV

Status: Beta: Mangler server og har ikke testet tung trafikk.

Jeg laget denne nettsiden for at NRK og TV2 fjernet Tekst-TV, som gjorde at mange eldre mistet muligheten til å lese nyehetene. Med denne nettsiden håper jeg at flere kan få tilbake Tekst-TV i stua. Nettsiden kjører på SpringBoot, med Java som back-end. Nyhetene kommer fra NRK sitt RSS API. Serveren oversetter RSS til lesbar JSON, og som gjør at en html nettside kan lese det. Nettsiden er så og si ferdig, men mangler en dedikert server, så får bare kjørt den lokalt akkurat nå.

  • Java
  • SpringBoot
  • HTML, CSS, JS
